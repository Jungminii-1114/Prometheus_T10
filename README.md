# PtoVen (Prometheus + Beethoven)

> AI기반 실시간 피아노 연주 가이드와 Practice Coach Agent를 결합한 초보자용 피아노 연습 서비스

# Introduction
---
피아노 초보자는 악보에서 읽은 음을 실제 건반에서 찾고, 자신의 실수를 파악하며, 적절한 방법으로 반복 연습하는 과정을 동시에 수행해야 합니다.
기존의 일반적인 낙하형 피아노 가이드와 달리 **PtoVen**은 카메라로 건반의 손의 위치를 관찰하고, MIDI⋅터치 입력을 통해 실제 연주를 판정한 뒤, Practice Coach Agent가 사용자의 상태에 맞는 연습 전략을 선택하는 서비스입니다.

단순히 연주가 끝난 후 결과표를 제공하는 것이 아니라 다음의 폐쇄 루프를 만드는 것이 핵심입니다.

```text
관찰 → 오류⋅취약 구간 분석 → 연습 전략 선택 → UI⋅템포 변경 → 재연주 → 효과 확인
```

## Core Values
- **동적 건반 가이드**: 다음에 연주할 건반을 초보자가 이해하기 쉽게 박자에 맞춰 표시합니다.
- **정확한 연주 판정**: MIDI 또는 iPad 터치 이벤트를 기준으로 음정과 타이밍을 판정합니다.
- **손가락 관측**: MediaPipe를 이용하여 연주에 올바른 손과 손가락 위치를 추정⋅평가합니다.
- **동적 연습 개입**: Agent가 구간, 템포, 손 분리, 힌트 강도를 실제 연습 중에 변경합니다.
- **개인화 상세 분석 레포트**: 연주 결과뿐 아니라 반복된 어려움과 개입 전후의 변화의 설명을 QR로 제공합니다.
